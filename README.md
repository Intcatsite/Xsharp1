## X Sharp (X#) - csharp1 Release

**X Sharp** — это высокоуровневый язык программирования разработанный на базе **C++** для работы в среде Linux. Система использует транслятор, преобразующий исходный код `.xs` в нативный исполняемый файл через компилятор G++.

---

### Инструкция по развертыванию (Linux).

#### 1. Подготовка окружения

Убедитесь, что в системе установлен компилятор G++:

```bash
sudo apt update
sudo apt install build-essential

```

#### 2. Сборка ядра csharp1

Скомпилируйте исходный код ядра в бинарный файл:

```bash
g++ -o csharp1 kernel.cpp

```

#### 3. Исполнение кода

Запуск программ осуществляется через передачу файла с расширением `.xs` в качестве аргумента команде `play`:

```bash
./csharp1 play main.xs

```

---

### Спецификация синтаксиса

В релизе **csharp1** реализованы следующие обязательные конструкции:

* **Декларация модулей**: Использование внешних функций (например, рандома) требует предварительного запроса через `give.me`.
* **Объявление переменных**: Строгая структура `var(type_var=...; name="...")`.
* **Ввод данных**: Интерактивный ввод через консоль с использованием `type_var=input`.
* **Условные операторы**: Проверка условий через `?(if_type=...)` и блок исключения `???:`.
